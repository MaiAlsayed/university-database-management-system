# University Database Management System

## Project Overview
A database project developed using Microsoft Access to organize and manage university-related information.

## Technologies Used
- Microsoft Access
- Relational Database Tables
- Forms and Reports

## My Role
**Form Design and Database Development Team Member**

- Designed and formatted database forms, including layouts, colors, and navigation buttons.
- Contributed to creating and organizing database tables.
- Participated in preparing reports to present database information in an organized format.

## Database Components
The project includes tables for managing information related to:
- Students
- Departments
- Professors
- Classes and Courses

## Project Purpose
To organize university data and provide a structured way to manage and display information through forms and reports.
